1 · Bases des réseaux

Comprendre ce qu'est un réseau, comment les données circulent, et les modèles de référence.

Qu'est-ce qu'un réseau ?

Un réseau informatique est un ensemble d'équipements (ordinateurs, serveurs, imprimantes, téléphones…) reliés entre eux pour partager des ressources et communiquer.

On distingue selon la taille :

Ethernet et adresse MAC

Une adresse MAC est une adresse physique de 48 bits, gravée sur la carte réseau, notée en hexadécimal : 00:1A:2B:3C:4D:5E.

  • Les 3 premiers octets = OUI (constructeur)
  • Les 3 derniers = numéro de série

Types de trames Ethernet : Unicast (une destination), Broadcast (FF:FF:FF:FF:FF:FF), Multicast.

Domaine de collision vs domaine de diffusion

Domaine de collision

Zone où deux machines peuvent entrer en collision. Le switch crée un domaine de collision par port. Le hub n'en crée qu'un seul pour tous.

Domaine de diffusion

Zone atteinte par un broadcast. Le routeur (ou un VLAN) sépare les domaines de diffusion. Le switch ne les sépare pas.

2 · Adressage IPv4

L'adresse IP est le cœur du réseau. Maîtrise-la parfaitement.

Structure d'une adresse IPv4

Une adresse IPv4 fait 32 bits, écrite en 4 octets séparés par des points (notation décimale pointée).

192  .  168  .   1   .   10
11000000.10101000.00000001.00001010   → 32 bits

Une adresse se compose de deux parties :

  • Partie réseau (Network) : identifie le réseau
  • Partie hôte (Host) : identifie la machine dans ce réseau

C'est le masque de sous-réseau qui détermine où s'arrête la partie réseau.

Formule magique

Nombre d'hôtes utilisables = 2(32 − CIDR) − 2
On retire 2 car : la 1ʳᵉ adresse = adresse réseau, la dernière = adresse de broadcast.

ARP - résolution d'adresse

ARP (Address Resolution Protocol) fait le lien entre une adresse IP et une adresse MAC.

  1. La machine veut joindre 192.168.1.20
  2. Elle envoie un ARP Request en broadcast : « Qui a 192.168.1.20 ? »
  3. La machine concernée répond en unicast : « C'est moi, voici ma MAC »
  4. Le résultat est stocké dans le cache ARP (arp -a)
À retenir

Si la destination est sur le même réseau → ARP sur la destination.
Si la destination est sur un autre réseau → ARP sur la passerelle par défaut.

3 · Subnetting

Découper un réseau en sous-réseaux. La compétence reine du CCNA.

Pourquoi subdiviser ?

  • Réduire le domaine de diffusion (moins de trafic parasite)
  • Sécuriser (isoler les services)
  • Optimiser l'utilisation des adresses
  • Organiser (un sous-réseau par service/étage)

Méthode en 5 étapes

Procédure
  1. Identifier le CIDR et le masque
  2. Calculer le pas (incrément) : 256 − dernier octet du masque
  3. Lister les adresses réseau (multiples du pas)
  4. Pour chaque sous-réseau : réseau = multiple du pas, broadcast = suivant − 1
  5. Hôtes utilisables = entre les deux

Exemple complet : 192.168.1.0/26

Étape 1 - /26 → masque 255.255.255.192

Étape 2 - Pas = 256 − 192 = 64

Étape 3 - Sous-réseaux : 0, 64, 128, 192

2192.168.1.64192.168.1.65192.168.1.126192.168.1.127
3192.168.1.128192.168.1.129192.168.1.190192.168.1.191
4192.168.1.192192.168.1.193192.168.1.254192.168.1.255

Astuce express

Pour trouver l'adresse réseau d'une IP comme 192.168.1.100/26 :
Pas = 64 → multiples : 0, 64, 128, 192. Or 100 est entre 64 et 127 → réseau = 192.168.1.64, broadcast = 192.168.1.127.

VLSM (Variable Length Subnet Mask)

Le VLSM permet d'utiliser différents masques dans un même réseau, pour ne pas gaspiller d'adresses. On attribue du plus grand besoin au plus petit.

Exemple : réseau 192.168.1.0/24 à découper pour :

  • Service A : 100 hôtes → /25 (126 hôtes) → 192.168.1.0/25
  • Service B : 50 hôtes → /26 (62 hôtes) → 192.168.1.128/26
  • Service C : 20 hôtes → /27 (30 hôtes) → 192.168.1.192/27
  • Liaison WAN : 2 hôtes → /30 → 192.168.1.224/30
Ordre obligatoire

En VLSM, on commence toujours par le sous-réseau qui a le plus grand besoin. Sinon on crée des trous et des chevauchements.

Exercices corrigés

Exercice 1 - Analyser 172.16.5.130/25 Facile

Question : Donne l'adresse réseau, le broadcast, la plage d'hôtes et le nombre d'hôtes.

Correction :

Masque /25 = 255.255.255.128 → pas = 256 − 128 = 128

Multiples : 0, 128. Or 130 est entre 128 et 255.

  • Adresse réseau : 172.16.5.128
  • Broadcast : 172.16.5.255
  • Plage d'hôtes : 172.16.5.129 → 172.16.5.254
  • Hôtes : 2⁷ − 2 = 126

4 · IPv6

Le successeur d'IPv4. 128 bits au lieu de 32.

Pourquoi IPv6 ?

IPv4 ne dispose que de ~4,3 milliards d'adresses, épuisées depuis 2011. IPv6 offre 3,4 × 10³⁸ adresses - assez pour attribuer une adresse à chaque grain de sable de la planète.

Format d'une adresse IPv6

128 bits, notés en 8 groupes de 4 chiffres hexadécimaux séparés par :.

2001:0db8:0000:0000:0000:ff00:0042:8329

Règles de simplification

  1. Supprimer les zéros en tête de chaque groupe :
    2001:0db8:0000:0000:0000:ff00:0042:8329 → 2001:db8:0:0:0:ff00:42:8329
  2. Remplacer une seule séquence de groupes nuls par :: :
    → 2001:db8::ff00:42:8329
Attention

On ne peut utiliser :: qu'une seule fois par adresse, sinon on ne peut plus la reconstituer.

Types d'adresses IPv6

TypePréfixeRôle
Global Unicast2000::/3Équivalent public, routable sur Internet
Link-LocalFE80::/10Communication locale sur le lien, auto-générée
Unique LocalFC00::/7Équivalent des adresses privées
MulticastFF00::/8Diffusion à un groupe
Anycast-Le plus proche du groupe
Loopback::1/128Équivalent de 127.0.0.1

Il n'y a plus de broadcast en IPv6

EUI-64

Méthode pour générer automatiquement la partie hôte à partir de la MAC :

  1. Prendre la MAC : 00:1A:2B:3C:4D:5E
  2. Insérer FF:FE au milieu : 00:1A:2B:FF:FE:3C:4D:5E
  3. Inverser le 7ᵉ bit du 1ᵉʳ octet (bit U/L) : 02:1A:2B:FF:FE:3C:4D:5E

Coexistence IPv4 / IPv6

Double pile

L'équipement tourne en IPv4 et IPv6 simultanément. Solution la plus courante.

Tunneling

IPv6 encapsulé dans des paquets IPv4 pour traverser un réseau IPv4.

Traduction (NAT64)

Conversion entre les deux protocoles à la frontière.

Commandes IPv6 sur Cisco IOS

Router(config)# ipv6 unicast-routing
Router(config)# interface g0/0
Router(config-if)# ipv6 address 2001:db8:1::1/64
Router(config-if)# ipv6 address fe80::1 link-local
Router# show ipv6 interface brief
Router# show ipv6 route

6 · VLAN & Trunk

Segmenter logiquement un switch physique.

Qu'est-ce qu'un VLAN ?

Un VLAN (Virtual LAN) est un réseau logique créé sur un ou plusieurs switches. Chaque VLAN = un domaine de diffusion distinct.

Avantages :

  • Réduction du trafic broadcast
  • Sécurité (isolation des services)
  • Flexibilité (regroupement par fonction, pas par emplacement)
  • Réduction des coûts (moins de câblage)

VLAN par défaut

VLANNomRôle
1defaultTous les ports y sont par défaut
1002–1005fddi, token-ring…Réservés (anciens protocoles)
2–1001-VLAN normaux (utilisables)
1006–4094-VLAN étendus

Ports d'accès vs ports trunk

Port Access

Appartient à un seul VLAN. Relie un PC, une imprimante, un serveur. La trame circule sans étiquette.

Port Trunk

Transporte plusieurs VLAN. Relie switch↔switch ou switch↔routeur. Les trames sont étiquetées 802.1Q.

802.1Q - l'étiquetage

Le protocole 802.1Q insère une étiquette de 4 octets dans la trame Ethernet, contenant l'ID du VLAN (12 bits → 4094 VLAN possibles).

Le VLAN natif (par défaut VLAN 1) circule sans étiquette sur le trunk.

Configuration VLAN sur un switch

Switch# configure terminal
Switch(config)# vlan 10
Switch(config-vlan)# name ADMIN
Switch(config-vlan)# exit

Switch(config)# vlan 20
Switch(config-vlan)# name TECH
Switch(config-vlan)# exit

! Affecter un port à un VLAN
Switch(config)# interface fa0/1
Switch(config-if)# switchport mode access
Switch(config-if)# switchport access vlan 10
Switch(config-if)# exit

! Configurer un trunk
Switch(config)# interface g0/1
Switch(config-if)# switchport mode trunk
Switch(config-if)# switchport trunk native vlan 99
Switch(config-if)# switchport trunk allowed vlan 10,20,99
Switch(config-if)# exit

Switch# show vlan brief
Switch# show interfaces trunk

Router-on-a-stick

Un routeur avec une seule interface physique peut router entre plusieurs VLAN grâce à des sous-interfaces.

Router(config)# interface g0/0
Router(config-if)# no shutdown
Router(config-if)# exit

Router(config)# interface g0/0.10
Router(config-subif)# encapsulation dot1Q 10
Router(config-subif)# ip address 192.168.10.1 255.255.255.0
Router(config-subif)# exit

Router(config)# interface g0/0.20
Router(config-subif)# encapsulation dot1Q 20
Router(config-subif)# ip address 192.168.20.1 255.255.255.0
Router(config-subif)# exit
Côté switch

Le port relié au routeur doit être en mode trunk, et le VLAN natif doit correspondre des deux côtés.

VTP (VLAN Trunking Protocol)

VTP permet de propager automatiquement la base VLAN entre switches. 3 modes :

ModePeut créer/modifierPropagation
ServerOuiEnvoie et reçoit
ClientNonReçoit
TransparentOui (localement)Relaye sans appliquer
Danger du VTP

Un switch avec une révision VTP plus élevée peut écraser la base VLAN de tout le domaine. Toujours vérifier le numéro de révision avant d'introduire un switch.

7 · Routage

Comment les paquets trouvent leur chemin d'un réseau à l'autre.

Le rôle du routeur

Un routeur relie des réseaux différents. Il consulte sa table de routage pour chaque paquet et choisit la meilleure route selon :

  1. La correspondance la plus longue (longest prefix match)
  2. La distance administrative (AD) - plus basse = plus fiable
  3. La métrique du protocole

Distance administrative (AD)

Table de routage - lecture

     192.168.1.0/24 is variably subnetted
C    192.168.1.0/24 is directly connected, GigabitEthernet0/0

  • S = statique, S* = route par défaut

Routage statique

! Route vers un réseau précis
Router(config)# ip route 192.168.2.0 255.255.255.0 10.0.0.2

! Route par défaut (vers Internet)
Router(config)# ip route 0.0.0.0 0.0.0.0 10.0.0.2

! Route statique via une interface de sortie
Router(config)# ip route 192.168.3.0 255.255.255.0 g0/1
Quand utiliser du statique ?

Petits réseaux, liens WAN stables, route par défaut vers le FAI. Avantages : pas de CPU, pas de bande passante, sécurisé. Inconvénient : pas d'adaptation automatique en cas de panne.

Routage dynamique - OSPF

OSPF (Open Shortest Path First) est un protocole à état de liens utilisant l'algorithme Dijkstra (SPF). C'est le plus utilisé en entreprise.

Caractéristiques :

  • Standard ouvert (pas propriétaire Cisco)
  • Métrique = coût basé sur la bande passante
  • Convergence rapide
  • Utilise des aires (areas) - l'aire 0 est la dorsale
  • Diffusion par multicast 224.0.0.5 et 224.0.0.6

Configuration OSPF simple

Router(config)# router ospf 1
Router(config-router)# router-id 1.1.1.1
Router(config-router)# network 192.168.1.0 0.0.0.255 area 0
Router(config-router)# network 10.0.0.0 0.0.0.3 area 0
Router(config-router)# exit

! Vérification
Router# show ip ospf neighbor
Router# show ip ospf interface brief
Router# show ip route ospf
Wildcard mask

OSPF utilise un masque générique (wildcard) = inverse du masque.
/24 → 0.0.0.255  |  /30 → 0.0.0.3  |  /16 → 0.0.255.255

8 · Services réseau

DHCP, DNS, NAT - les services indispensables.

DHCP

DHCP (Dynamic Host Configuration Protocol) attribue automatiquement une configuration IP aux machines. Port UDP 67 (serveur) et 68 (client).

Les 4 étapes - DORA

NAT / PAT

NAT (Network Address Translation) traduit les adresses privées en adresses publiques.

TypePrincipe
NAT statique1 IP privée ↔ 1 IP publique (fixe)
NAT dynamiquePool d'IP publiques attribuées à la demande
PAT (NAT overload)Plusieurs IP privées ↔ 1 IP publique, différenciées par les ports

Terminologie NAT

  • Inside local : IP privée de la machine interne
  • Inside global : IP publique vue de l'extérieur
  • Outside local/global : équivalents pour l'extérieur

Configuration PAT (la plus courante)

Router(config)# interface g0/1
Router(config-if)# ip nat outside
Router(config-if)# exit

Router(config)# interface g0/0
Router(config-if)# ip nat inside
Router(config-if)# exit

Router(config)# access-list 1 permit 192.168.1.0 0.0.0.255
Router(config)# ip nat inside source list 1 interface g0/1 overload

! Vérification
Router# show ip nat translations
Router# show ip nat statistics

NAT statique

Router(config)# ip nat inside source static 192.168.1.10 203.0.113.10
Pourquoi le PAT ?

Une seule adresse publique peut supporter plus de 65 000 connexions simultanées grâce aux numéros de port. C'est ce qui a permis de retarder l'épuisement d'IPv4.

Les ACL - Access Control Lists

Une ACL est une liste de règles qui autorisent ou refusent le trafic. Elles se lisent de haut en bas et s'arrêtent à la première correspondance.

Règle d'or

À la fin de toute ACL, il y a un deny any implicite invisible. Si tu ne termines pas par un permit, tout le reste est bloqué !

ACL standard vs étendue

CritèreStandardÉtendue
Numéros1–99, 1300–1999100–199, 2000–2699
Filtre surIP source uniquementSource, destination, protocole, ports
EmplacementAu plus près de la destinationAu plus près de la source

ACL standard

Router(config)# access-list 10 permit 192.168.1.0 0.0.0.255
Router(config)# access-list 10 deny any

Router(config)# interface g0/0
Router(config-if)# ip access-group 10 in

ACL étendue

! Autoriser le web (HTTP/HTTPS) vers le serveur 10.1.1.5
Router(config)# access-list 100 permit tcp 192.168.1.0 0.0.0.255 host 10.1.1.5 eq 80
Router(config)# access-list 100 permit tcp 192.168.1.0 0.0.0.255 host 10.1.1.5 eq 443
Router(config)# access-list 100 permit tcp any any established
Router(config)# access-list 100 deny ip any any

Router(config)# interface g0/1
Router(config-if)# ip access-group 100 in

ACL nommée (plus lisible)

Router(config)# ip access-list extended BLOQUE_TELNET
Router(config-ext-nacl)# deny tcp any any eq 23
Router(config-ext-nacl)# permit ip any any
Router(config-ext-nacl)# exit

Modes de violation :

  • shutdown (défaut) : port désactivé, err-disabled
  • restrict : paquets droppés, log + compteur
  • protect : paquets droppés silencieusement
